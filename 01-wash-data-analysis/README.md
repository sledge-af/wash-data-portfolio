# WASH Data Analysis — Nigeria

## Objective
Analyze WASH-related data to identify service coverage,
inequalities and key trends.

## Tools
- Microsoft Excel
- Power BI
- Python

## Key Questions
1. What percentage of households have access to basic water services?
2. How does access vary across locations?
3. What major patterns or gaps can be identified?

## Deliverables
- Cleaned dataset
- Excel analysis
- Charts
- Findings report
